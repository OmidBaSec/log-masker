✏ Edit / add analysis templates

        
      

      
Edit any template's prompt and MITRE mapping, then
        Save — changes apply to every analysis and survive

        keywords drive the auto-suggestion from a pasted log.

      

        
      

      

      

    

  


  
  

    

      

        
🧩 Masking patterns

        
      

      
All built-in regexes, grouped by log source type. Edit one and
        press Save — it applies to every future paste and survives
        restarts (stored locally in builtin_overrides.json). If a regex
        contains a capture group, only the group is masked; otherwise the whole
        match. Patterns run top to bottom — earlier matches win. ↺ default
        restores the original regex.
